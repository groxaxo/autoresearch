Design Principles

Single File to Modify

The agent only edits train.py. Diffs are small, readable and reversible. prepare.py is never touched.

Fixed Time Budget

Every run lasts exactly 5 minutes (wall-clock, excluding compile). Models of all sizes compete on equal footing.

Vocab-Independent Metric

val_bpb (bits per byte) normalises by token byte length, so architectural changes are fairly compared regardless of vocabulary size.

Fully Autonomous

The agent never pauses to ask the human for continuation. The human programs the strategy in program.md, not the experiments.

6

CausalSelfAttention
Pre-norm → Q,K,V proj → VE mix → RoPE → QK-norm → FA3 → out-proj
MLP
Pre-norm → fc (×4) → relu² → proj
Output Head
RMS Norm → lm_head Linear → softcap(logits, 15) → cross-entropy

Rotary Embeddings (RoPE)

Pre-computed cos/sin buffers up to sequence_len × 10. Base = 10 000. Applied to Q and K after QK-norm. bfloat16 precision.

Sliding Window Attention

Pattern characters map to window sizes: L = sequence_len, S = sequence_len/2. Pattern cycles; last layer is always forced to L (full context).

Value Residual (ResFormer)

On VE layers: v = c_v(x) + gate·ve(idx). Gate = 2·σ(linear(x[…,:32])). Initialised neutral (gate ≈ 1).

Per-Layer Scaling

resid_lambdas (init 1.0) scales the residual stream. x0_lambdas (init 0.1) mixes in the post-embedding anchor x₀.

Logit Soft-Cap

Final logits capped via 15·tanh(logits/15) to prevent training instability. Logits converted to float32 before the cap.

Memory Tricks

Meta-device instantiation → to_empty(device) → custom init. Embeddings cast to bfloat16. PYTORCH_ALLOC_CONF expandable segments. GC frozen after step 0.

MuonAdamW Optimizer

Muon — 2D Matrix Parameters

  • Applies to all attention and MLP weight matrices
  • Nesterov momentum buffer (0.85 → 0.95 ramp over 300 steps)
  • Polar Express orthogonalisation: 5-iteration polynomial approximation of matrix square root
  • NorMuon variance reduction: adaptive per-head step size via second-moment buffer
  • Cautious weight decay: WD masked to params where grad and param share sign
  • LR scaled by √(max(1, rows/cols)) for non-square matrices
  • WD linearly anneals to 0 during training

AdamW — Embeddings & Scalars

  • lm_head (unembedding) — lr = UNEMBEDDING_LR × scale
  • wte (token embedding) — lr = EMBEDDING_LR × scale
  • value_embeds — lr = EMBEDDING_LR × scale
  • resid_lambdas — lr = SCALAR_LR × 0.01
  • x0_lambdas — lr = SCALAR_LR, β₁=0.96
  • No weight decay on any AdamW group
  • All steps fused via @torch.compile(fullgraph=True)

LR Scaling Rule

All AdamW learning rates are multiplied by 1 / √(n_embd / 768) so that the tuned defaults generalise across model sizes (baseline tuned at 768 embedding dim).

val_bpb Evaluation Metric

val_bpb = Σ(per-token cross-entropy nats) / (ln(2) × Σ(target byte lengths))

  • Lower is better.
  • Special tokens (byte_length = 0) are excluded from both sums.
  • Uses fixed MAX_SEQ_LEN and VAL_SHARD so results are reproducible and comparable.
  • Vocab-size independent — architectural changes with different vocab sizes are fairly compared.

Agent protocol and research strategy. Edited by the human.

Setup Phase (run once)

  • Create a new git branch for the experiment run
  • Read and understand prepare.py and train.py
  • Read results.tsv history if it exists
  • Create results.tsv with header if needed

results.tsv Format

  • commit — short git hash
  • val_bpb — evaluation metric
  • memory_gb — peak VRAM usage
  • status — "keep" or "revert"
  • description — what changed

Constraints

  • Never modify prepare.py
  • Never install new packages
  • Each run ≤ ~10 min total wall time
  • Prefer simplicity over marginal gains
  • Never pause to ask human to continue

Crash / Timeout Handling

  • Fast-fail: if train_loss > 100 → exit(1)
  • OOM: reduce DEVICE_BATCH_SIZE and retry
  • Timeout: treat as failed, git reset
  • Missing output line: treat as failed
